# Pippo: Adopt Me! 

## Adopt Pippo - a baby and live till it grows up! 

![Pippo](image.png)

## Features
- Learn Skills, Take care of Pippo, Study with Pippo and many more.
- **Fast Setup:** Get up and running in minutes.
- **Clean UI:** Designed for simplicity and ease of use.

## Installation
Clone the repository and install dependencies:
```bash
git clone https://github.com/SUP120/pippo-adopt-me
cd https://github.com/SUP120/pippo-adopt-me
npm install
```
